# 기술 결정: 음성 메모 + AI 구조화

**날짜**: 2026-05-09  
**결정자**: sml122900

---

## 배경

포지션 메모 기능에 음성 입력을 추가한다.  
단순 STT가 아니라 Claude/Gemini API를 활용해 발화 내용을 진입이유·청산이유·심리상태 등 필드로 자동 분류하는 것이 목표.

---

## 결정 1 — STT 방식: 브라우저 Web Speech API

### 선택지 비교

| | Web Speech API | Gemini native audio |
|---|---|---|
| 비용 | 무료 | 오디오 1분 ≈ $0.002 |
| 실시간 | O (말하는 즉시 표시) | X (1~3초 딜레이) |
| 정확도 | 중간 (전문 용어 오인식 있음) | 높음 |
| 구현 난이도 | 낮음 | 높음 (오디오 파일 서버 전송 필요) |
| 브라우저 지원 | Chrome/Edge 전용 | 전체 |
| 개인정보 | Google 서버 경유 | Google AI 서버 경유 |

### 결정: Web Speech API

**이유**: STT 오인식은 이후 AI 구조화 단계에서 문맥 보정으로 상당 부분 커버된다.  
실시간 피드백이 UX상 훨씬 자연스럽고, 추가 API 비용 없이 구현 가능.  
Gemini native audio는 향후 "고급 설정" 옵션으로 추가 가능.

---

## 결정 2 — AI 역할: 필드 자동 분류 (구조화)

### 선택지 비교

| | 텍스트 그대로 붙여넣기 | 필드 자동 분류 | 분류 + 코칭 멘트 |
|---|---|---|---|
| API 비용 | 없음 | 약 $0.001~0.003/회 | 더 높음 |
| 처리 속도 | 즉시 | 1~3초 | 3~5초 |
| 5개 필드 활용 | X (자유메모 한 칸에 몰림) | O | O |
| 구현 복잡도 | 낮음 | 중간 | 높음 |
| 틀린 분류 위험 | 없음 | 있음 (검토 필요) | 있음 + 잘못된 조언 위험 |

### 결정: 필드 자동 분류

**이유**: 텍스트 그대로 넣으면 음성 등록의 핵심 가치(두서없이 말해도 정리됨)가 사라진다.  
코칭 멘트는 "AI 분석" 탭으로 별도 구현하는 편이 UX상 명확하다.  
AI가 포지션 정보(심볼, 방향, PnL, 시간)를 컨텍스트로 받아 분류 정확도를 높인다.

**AI 프롬프트 구조**:
```
포지션 정보: BTC Long, +$1,240, 2× 레버리지
사용자 발화: "..."

다음 JSON으로 분류:
{ "reason": "", "exitReason": "", "psych": "", "external": "", "text": "" }
분류 불가 내용은 text에 넣을 것. 없는 항목은 빈 문자열.
```

## 결정 3 — 모델 선택: 모달 드롭다운 + 설정 기본값

### 선택지 비교

| | 매번 선택 (풀 카드 UI) | 설정 기본값 1개 | 모달 드롭다운 + 설정 기본값 |
|---|---|---|---|
| 유연성 | 최고 | 없음 | 중간 |
| 모달 복잡도 | 높음 | 낮음 | 낮음 |
| 구현 복잡도 | 높음 | 낮음 | 중간 |
| UX | 매번 선택 피로 | 변경 불편 | 균형 |

### 결정: 모달 드롭다운 + 설정 기본값

**이유**: 대부분의 경우 같은 모델을 반복 사용하므로 기본값을 설정 페이지에서 지정.  
필요시 모달 내 드롭다운으로 즉시 변경 가능. 모달 UI는 단순하게 유지.

**모달 UI**: `[모델: Gemini Flash ▾]` 드롭다운 1개  
**설정 페이지**: 카드 선택 UI (이미지 참고) — Gemini / Claude 각 티어별 선택

### 지원 모델 목록

| 브랜드 | 표시명 | 모델 ID | 특징 |
|---|---|---|---|
| Gemini | Flash-Lite | gemini-2.0-flash-lite | 빠름, 저비용 |
| Gemini | Flash | gemini-2.0-flash | 권장, 균형 |
| Gemini | Pro | gemini-1.5-pro | 고품질, 고비용 |
| Claude | Sonnet | claude-sonnet-4-6 | 균형, 저비용 |
| Claude | Opus | claude-opus-4-7 | 고품질, 고비용 |

## 구현 범위

1. `Settings` 페이지 — AI API 키 섹션 (Anthropic / Google AI), 기본 모델 카드 선택 UI
2. DB 스키마 — AI 키 필드 추가 (AES-256-GCM 암호화)
3. `/api/ai/structure-memo` — STT 텍스트 + 포지션 컨텍스트 → 선택 모델 호출 → JSON 반환
4. `MemoModal` — 음성 녹음 버튼, Web Speech API 연동, 모델 드롭다운, AI 처리 상태 표시

## 포기한 대안

- Gemini native audio STT: 비용·구현 복잡도 대비 이득 불충분. 추후 고급 옵션으로 검토.
- 코칭 멘트 자동 생성: 별도 "AI 분석" 기능으로 분리 예정.
- 풀 카드 모델 선택 UI (모달 내): 설정 페이지에만 두고 모달은 드롭다운으로 단순화.
