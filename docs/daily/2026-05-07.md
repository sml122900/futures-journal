# 2026-05-07 작업 일지

## 작업 내용

### 1. 온보딩 플로우 구현
- 로그인 후 API 키 등록 여부 확인 → 미등록 시 안내 화면으로 리다이렉트
- 거래소 선택 화면 (바이낸스, 바이비트, OKX, 비트겟, 빙엑스)
- 거래소별 API 입력 폼 (Passphrase 유무 조건부 표시)
- 거래소별 API 등록 가이드 페이지 + 보안 주의사항
- `src/lib/exchanges.ts`로 거래소 설정 분리

### 2. DB 스키마 변경
- `ApiKey` 모델에 `exchange` 필드 추가
- `userId` 단독 unique → `@@unique([userId, exchange])`로 변경 (거래소별 다중 키 지원)
- `prisma db push --accept-data-loss`로 반영

### 3. 대시보드 전면 구현
- HTML 프로토타입의 모든 기능을 Next.js로 포팅
- 3탭 네비게이션 (매매 내역 / 현재 포지션 / 설정)
- 통계 패널 4개 (잔고 / 건수 / 순손익 / 승률)
- 기간 필터 3모드: 빠른선택(7~90일) / 직접선택(날짜 범위) / 전체기간(90일 청크 분할)
- 자동갱신 토글 + 주기 설정
- 주문 내역 테이블: 심볼/방향/Open·Close 필터, 페이지네이션(20개), 순손익 툴팁
- 포지션 내역 테이블: 심볼/방향 필터, 펀딩피·수수료 컬럼, 툴팁
- 현재 포지션 카드 (진입가/현재가/청산가/미실현손익)
- 메모 모달 (진입이유/심리/외부변수/자유메모 라디오필) → DB 저장
- 진행바 (전체기간 청크 로딩 시)

### 4. 유저 드롭다운 메뉴
- 헤더에 아바타 버튼 (이름 첫 글자)
- 클릭 시 드롭다운: 유저 정보, 거래소 연결 상태, 회원정보 수정, API 키 관리, 로그아웃
- 회원정보 수정 페이지 (`/settings/profile`): 이름 / 비밀번호 변경

### 5. 테마 시스템
- 다크모드 / 화이트모드 / 시스템 설정과 동일 3가지 지원
- `ThemeProvider` + `useTheme` 훅 구현
- Tailwind v4 유틸리티 클래스 직접 오버라이드 방식으로 라이트 모드 구현
- 화면 깜빡임 방지: `<head>` 인라인 스크립트로 JS 실행 전 테마 적용
- `localStorage`에 저장, 새로고침 후에도 유지

### 6. 트러블슈팅
- Bitget fills API 필드명 불일치 (`price`/`profit`/`feeDetail` vs 예상한 `priceAvg`/`totalProfits`/`fee`)
- Bitget `orderId` 중복 key 오류 → `tradeId`로 교체
- 화이트 모드 미적용 → Tailwind v4 CSS 변수 방식 불가, 클래스 직접 오버라이드로 재작성
- 브라우저 확장 프로그램(Bitdefender) hydration 경고 → `<html>`, `<body>` suppressHydrationWarning 적용

## 결정 사항
| 결정 | 이유 |
|------|------|
| Tailwind 클래스 직접 오버라이드 | v4는 CSS 변수 오버라이드 방식 미지원 |
| `tradeId`를 row key로 사용 | `orderId`는 fills에서 중복됨 |
| `text-force-white` 커스텀 클래스 | 배지 글씨가 라이트 모드 오버라이드에 영향받는 것 방지 |
