### 3. 리플레이(매매 영상화) 기능 구현
- `/app/replay/page.tsx` — TradingView Lightweight Charts v5 기반 리플레이 플레이어
- `/api/bitget/candles/route.ts` — OHLCV 캔들 API (1000봉 초과 자동 분할 병합)
- 포지션 내역 테이블에 `▶ Replay` 버튼 추가
- 기능: 캔들 애니메이션 재생, 1×/2×/4×/8× 배속, 타임라인 슬라이더, TF 선택
- 사이드바: 체결 내역 카드 실시간 하이라이트, 재생에 따라 자동 스크롤
- 차트 오버레이: Avg Entry / Size / Unrealized PnL / Realized PnL / Total PnL
- 평단가 점선: 수수료 포함 가중평균, 체결마다 실시간 업데이트
- UTC 오프셋 설정 (-10~+13), localStorage 저장

### 4. 리플레이 버그 수정 (다수)
- lightweight-charts v5 API 변경 대응: `addCandlestickSeries` → `addSeries(CandlestickSeries)`
- Hydration 오류: `toLocaleString` → 수동 날짜 포맷, `localStorage` 초기값 → `useEffect`로 이전
- 영상 조기 종료: `actualTo`를 CLOSE 타입이 아닌 마지막 fill 시각으로 수정, 캔들 범위 ±1시간 확보
- 평단가 소멸 버그: PARTIAL_CLOSE 누적 시 avg 리셋되던 문제 수정 (`CLOSE` 타입만 리셋)
- Hedge mode 필터링: Bitget fills API의 `side` 필드가 포지션 방향(buy=롱, sell=숏)임을 파악, `o.side === "buy"` 기준으로 롱/숏 완전 분리
