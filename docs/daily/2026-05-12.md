# 2026-05-12 작업 일지

## 작업 내용

### 내보내기 기능 — Bitget 원본 형식 + 메모 (CSV / Excel)

- `/api/export/csv` 리라이트:
  - `type=positions`: Bitget 원본 컬럼(`Futures`, `Opening time`, `Average entry/closing price`, `Closed amount/value`, `Position Pnl`, `Realized PnL`, `Fees`, `Opening/Closing fee`, `Closed time`) + 진입이유·청산이유·심리상태·자유메모
  - `type=orders`: Bitget 원본 컬럼(`Order ID`, `Direction`, `Futures`, `Order source`, `Transaction type`, `Price`, `Average Price`, `Order amount`, `Executed`, `Trading volume`, `Realized P/L`, `NetProfits`, `Status`, `Time`)
  - 90일 청크 자동 분할 + `idLessThan` 페이지네이션 (최대 10페이지/청크)
  - `from` 미지정 시 최근 1년 자동 적용

- `/api/export/excel` 업데이트:
  - `?type=positions`: Bitget 형식 단일 시트 + 메모 컬럼
  - `?type=orders`: Bitget 형식 단일 시트
  - 파라미터 없음: 기존 5시트 전체 저널 유지
  - 플랜 게이팅 제거 (모든 사용자 사용 가능)
  - 동일한 90일 청크 분할 적용

- `/settings/export/page.tsx` 리디자인:
  - 3개 카드: 포지션 내역 / 매매 내역 / 전체 저널
  - 기간: 7일·30일·90일·전체 프리셋 + "직접" 버튼으로 from/to 날짜 피커 전환

### "클릭으로 선택" 범위 지정 내보내기

- `/settings/export`: "클릭으로 선택" 버튼 → `sessionStorage`에 section 저장 → `/dashboard` 이동
- `DashboardContent`: sessionStorage 감지 → 고정 배너 표시
  - Step 0: "시작 시점 더블클릭"
  - Step 1: "종료 시점 더블클릭" + 선택한 시작 시각 표시
  - Step 2: "형식 고르세요" + Excel / CSV 버튼 + 날짜 범위 표시
- 더블클릭된 행 색상 강조 (시작=파란색, 종료=주황색, 범위 내=연녹색)
- 다운로드 완료 후 선택 모드 자동 해제

## 결정 사항

| 결정 | 이유 |
|------|------|
| 내보내기 플랜 게이팅 제거 | 자신의 매매 데이터 내보내기는 핵심 기능 — 플랜 제한 부적절 |
| Network First 전략으로 전환 | Cache First는 개발 중 HMR 청크와 충돌, 인증 상태 변화에도 취약 |
| 90일 청크 분할 서버사이드 처리 | 비트겟 API 제한(90일/요청)을 클라이언트에서 처리하면 타임아웃 위험 |
| 클릭 선택 상태를 sessionStorage로 전달 | URL params는 Suspense 필요 — sessionStorage가 더 단순하고 안정적 |
