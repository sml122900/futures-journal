## 결정 사항

| 결정 | 이유 |
|------|------|
| `exchanges.ts` → `exchange-meta.ts` 이름 변경 | `exchanges/` 디렉토리와 이름 충돌 — Node.js는 파일이 디렉토리보다 우선이어서 디렉토리 index.ts 미인식 |
| Binance getClosedPositions: income + userTrades 병행 | income API만으로는 방향 불명 → userTrades.positionSide로 HEDGE/ONE-WAY 모두 처리 |
| Bitget 호환 raw 포맷 응답 유지 | DashboardContent 파서 변경 없이 모든 거래소 지원 — 추상화 레이어에서 필드명 정규화 |
| `tradesRef` + `closingRef` 패턴 | React setState updater 내부 fetch 금지 (strict mode 이중 실행) — ref로 최신 상태 읽기 분리 |
| 백테스트 진입가 = 다음 캔들 시가 | close 가격 알고 있는 상태에서 진입은 lookahead bias — 현실적인 slippage 근사 |
| 통계 지원 거래소 = bitget/binance만 | bybit/okx/bingx는 exchange factory 미구현 → 필터에서 제외해 500 에러 방지 |
