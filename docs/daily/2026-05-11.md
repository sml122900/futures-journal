## 결정 사항

| 결정 | 이유 |
|------|------|
| next-pwa 미사용 → 수동 SW | Next.js 16 Turbopack과 webpack 충돌, 수동 구현이 더 단순 |
| Subscription 모델 Toss 정기결제 키 필드 포함 | 추후 정기결제 연동 확장성 확보 |
| AI 코치 대화 DB 저장 (MAX_HISTORY=10) | 세션 간 컨텍스트 유지, 무한 확장 방지 |
| Cron CRON_SECRET 환경변수 보호 | Vercel Cron 미사용 시에도 외부 호출로 테스트 가능 |

## 빌드 오류 및 해결

| 오류 | 해결 |
|------|------|
| Next.js 16 동적 라우트 `params`가 `Promise` | `await params` 처리, RouteContext 타입 정의 |
| `next-pwa` Turbopack webpack 충돌 | `next-pwa` 제거, 수동 `sw.js` + `manifest.json` 방식으로 전환 |
| ExcelJS 동적 import 시 타입 불인식 | 정적 import로 변경 |
| Prisma Json 필드 타입 캐스팅 | `as unknown as TargetType` 두 단계 캐스팅 |
