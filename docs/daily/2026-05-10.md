## 작업 내용

### 1. 음성 메모 + AI 구조화 기능 구현
- MemoModal에 🎤 음성 녹음 버튼 추가 (Web Speech API, ko-KR)
- 녹음 중지 시 선택한 AI 모델(Claude/Gemini)로 음성 원문 자동 분류
- 5개 필드(진입이유·청산이유·심리·외부변수·자유메모)에 자동 채움
- 모델 드롭다운: 기본값 localStorage(`ai_model`) 저장, 변경 시 즉시 반영
- 크레딧 부족 시 "충전하기 →" 링크 표시

### 2. 크레딧 기반 수익화 시스템 구현
- `User.credits` 필드, `Purchase`, `CreditLog` 모델 추가 (prisma db push)
- `src/lib/credits.ts`: 패키지 상수, 모델별 차감량, SIGNUP_BONUS(30) 정의
- 가입 시 30 크레딧 자동 지급 (`/api/auth/register`)
- `/api/user/credits`: 잔액 조회
- `/api/ai/structure-memo`: 서버 env API 키 사용, 크레딧 확인 후 차감 (Prisma transaction)
- 대시보드 헤더에 크레딧 잔액 + "+충전" 링크 추가

### 3. Toss Payments 결제 연동
- `/payments` 페이지: 패키지 선택(4종) + Toss 결제창 연동
- `/payments/success` 페이지: 결제 완료 후 크레딧 지급 처리
- `/api/payments/confirm`: Toss API 서버 승인 → credits increment → CreditLog 기록 (transaction)
- orderId 형식: `{packageId}_{userId}_{timestamp}` — 서버에서 금액 검증에 활용
- 중복 결제 방지: `tossKey` unique 제약

### 4. AI 설정 페이지 개편
- `/settings/ai`: API 키 입력 섹션 제거, 크레딧 잔액 + 기본 모델 카드 선택 UI로 교체
- UserDropdown에 "🤖 AI 설정" 링크 추가

### 5. explain.md 생성
- 향후 Claude 세션에서 전체 컨텍스트 공유용 프로젝트 구조 문서 작성
- `docs/explain.md`

### 6. 버그 수정
- Hydration 오류 (브라우저 확장 BIS 주입): `<head>`·`<script>` 에 `suppressHydrationWarning` 추가
- 결제 페이지 로그인 리다이렉트: `useSession` status `"loading"` 중 리다이렉트 방지
- Toss 위젯 SDK 401: `@tosspayments/payment-widget-sdk` → `@tosspayments/payment-sdk` 전환 (일반 결제창)
- Google AI 할당량 초과(429): 에러 메시지 사용자 친화적으로 개선, Claude로 대체 안내

## 결정 사항
| 결정 | 이유 |
|------|------|
| 사용자 AI 키 등록 옵션 제거 | 기술 허들 낮은 타겟 사용자가 직접 키 등록 시 수익화 불가 |
| 결제 SDK를 위젯 → 일반 결제창으로 전환 | 위젯은 Toss 대시보드 별도 상품 활성화 필요, 일반 결제창은 즉시 사용 가능 |
| Web Speech API로 STT | 무료·실시간·서버 불필요, AI 구조화 단계에서 오인식 보정 |
| orderId에 packageId 인코딩 | Pending Purchase DB 생성 없이 서버에서 금액 검증 가능 |
